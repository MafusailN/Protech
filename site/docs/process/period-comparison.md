# Отчёт «Сравнение периодов»

Инструмент диагностики клиента/портфеля для МАПов. Применяется вместе с [ABC-сегментацией](abc-segmentation.md).

## Порядок работы

1. **Настройка периода** — месяц/квартал/год через «Настройки» → количество периодов сравнения → «закрыть сформировать».
2. **Динамика по брендам (общая)** — какие бренды растут/падают год к году.
3. **Динамика по брендам в разрезе конкретного клиента.**
4. **Динамика по бизнес-регионам** — доля региона в общей выручке + разбивка клиентов по регионам.
5. **Динамика по сферам деятельности** (например, падение доли монтажных компаний) + та же динамика по каждому клиенту сферы.
6. **Динамика по группам номенклатуры** — фильтр «номенклатура» → подбор → анализ по клиенту.
