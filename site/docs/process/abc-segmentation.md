# ABC-сегментация клиентов (правило Парето)

## Логика сегментации

1. Топ клиентов ранжируется по выручке (принцип Парето).
2. Из категории A исключаются разовые заказы и холдинги (холдинги объединяются с головной компанией в 1С).
3. **Категория A** — закреплена за ответственным менеджером, не трогаем.
4. **Категория B** — кандидат на перераспределение, но только если:
    - у МАПа уже больше 50 клиентов категории A, либо
    - МАП не может установить контакт с клиентом.
5. МАП может отстоять клиента у себя при наличии веских аргументов.
6. **Категория C** — «для поддержания штанов», не приоритет.

## Проверка потенциала клиента (перед переводом из B)

Через сайт «Русprofile»:

1. Сравниваем текущую выручку клиента у ПРОТЭК с официальным оборотом компании клиента.
2. Считаем гипотетическую долю монтажа/оборудования (50/50).
3. Выводим текущую долю ПРОТЭК у клиента.
    - Пример: 200 тыс. руб / 5 млн руб = 4%.
4. Цель — довести долю минимум до 10% по итогам года.

## Работа с категорией A

Детальный разбор на каждого клиента:

- Динамика (растёт/падает).
- Какие направления/бренды не берёт и почему.
- Полный портфель клиента (личная встреча/созвон): директор, закупщики (может быть несколько по направлениям), кто отвечает за оплаты, какие объекты ведутся в текущем году.
- На основе этого выставляется квартальный/годовой план на клиента с отслеживанием динамики.
