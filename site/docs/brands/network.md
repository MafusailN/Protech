# Сетевое оборудование

- **Dahua** — лидер по рентабельности (маржа существенно выше, чем у WiTek при сопоставимых продажах).
- **WiTek** — лидер по выручке (клиенты активно берут сами), но по рентабельности сильно уступает Dahua; сейчас цель — распродать излишние стоки.
- **Space Technology** (коммутаторы) — высокая рентабельность (~33%), готовится сертификат Минпромторг.
- **iFlow** — неплохая рентабельность на коммутаторах, появились свои точки доступа по интересной цене.

## Wi-Fi (точки доступа / бизнес Wi-Fi)

В стадии выбора нового официального партнёра:

- **IPCom** — премиум, конкурент TP-Link, интересная маржа ~40%+ по официальному прайсу.
- **Cudi** — рассматривается.
- **Ubiquiti** — неофициальный ввоз, риски по гарантии/сервису.

!!! warning "Решение отложено"
    Требуется техническая проверка (задача на 2 недели после встречи 14 февраля).
