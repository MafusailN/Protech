# Портфель брендов — обзор

## Легенда

<span class="brand-focus">🟠 Фокус</span> — активно продвигаем (маркетинг, обучение, мотивация менеджеров)
<span class="brand-stock">🔵 В наличии</span> — обеспечиваем ассортимент, но не продвигаем активно
<span class="brand-passive">⚪ Фоновый</span> — пассивный ассортимент, без отдельной политики

## Правильные написания брендов

Обязательно использовать именно так — в материалах и черновиках встречаются искажения.

| Как встречается в черновиках | Правильное написание |
|---|---|
| DAHO / Daho / DAFO | **Dahua** |
| E-Smart / eSmart / И-Смарт | **Esmart** / **Есмарт** |
| Proxway | **ProxWay** |
| Zkoteч / Zecotec / Zegotec / Секотека | **ZKTeco** / **ЗКТеко** |
| Teko | **ТЭКО** |
| Biward / Bivard | **Beward** |
| Smart iRK | **Smart AirKey** |
| Cardex / Кардекс / Kartics / Cartics | **Carddex** |
| Перка | **Перко** (Perco) |
| Bolid | **Болид** (кириллица) |
| Rubezh | **Рубеж** (кириллица) |
| Levicom / Левиком | **Livicom (Ливиком)** — латиница первая, кириллица в скобках |
| Elex / Temit | **Эликс** (дистрибьютор) |
| Satro | **Сатро-Палладин** |
| Rutec | **Рутек** |

| «Вайтек» / «ВайТэк» / Vytech / Bytek | **WiTek** |
