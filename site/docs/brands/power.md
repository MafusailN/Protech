# ИБП и БПП: источники питания

## ИБП (источники бесперебойного питания)

- 🟠 **SmartWatt** — фокусный бренд для решений 220В/380В. Хорошая линейка (1–20 кВт), развивающееся направление у дистрибьютора Энергон. Готовится дополнительная мотивация для менеджеров (4% от закупочной цены).
- 🔵 **Бастион** — сертификат Минпромторг, многолетний надёжный поставщик. Но: пожар на производстве в декабре 2024 — до сих пор перебои с поставками; цена не в рынке на не-Минпромторговские решения.
- Отклонены: EaPon (ужасный сервис, 100% рекламаций), PowerCom — нет выгодных условий.

## БПП 12В (слаботочные блоки питания)

- 🟠 **Linemax** — фокус, планы развития в SKS-бренд (совместно с витой парой), максимальная рентабельность (~24%) + отдельная мотивация менеджеров.
- Резервные варианты при отсутствии Linemax: **Бастион**, **Space Technology** (Аккортек/Accortec — тоже на складе).
