# Книга продаж ПРОТЭК

Внутренняя база знаний отдела продаж ООО «ПРОТЭК» — для менеджеров активных продаж (**МАП**) и менеджеров сопровождения продаж (**МСП**).

**«Безопасность по-честному»**

## С чего начать

- **Новый в компании?** Начните с раздела [«О компании»](company/about.md) — ценности, философия работы с клиентом, айдентика.
- **Подбираете оборудование?** Смотрите [«Портфель брендов»](brands/index.md) — какие бренды продвигаем, какие держим в наличии, аргументы для клиента.
- **Нужна цена/скидка?** Раздел [«Ценообразование»](pricing.md).
- **Работаете с дебиторкой?** [«Регламент ПДЗ»](process/pdz.md) и [«Отсрочка платежа»](process/credit-limit.md).
- **Планируете день?** [«Алгоритм рабочего дня МАП/МСП»](process/workday.md).
