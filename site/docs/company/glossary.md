# Термины и классификация клиентов

## Роли в отделе продаж

| Роль | Расшифровка | Зона ответственности |
|---|---|---|
| **МАП** | Менеджер активных продаж | Дебиторка, звонки, разбор заказов, подбор оборудования |
| **МСП** | Менеджер сопровождения продаж | Входящие платежи, заявки на анализ МАПу, уведомления об отгрузке, допродажа |

## Классификация клиентов

**По направлению деятельности:**

- Заказчик (конечник)
- Розничный покупатель
- Монтажник (инсталлятор)
- Интегратор
- ЧОП
- Торговая организация

**По обороту:** небольшой / средний / крупный / VIP

**По активности:** активный (лояльный) / спящий (заснувший) / архивный / пассажир

**По виду продажи:** канальный / проектный

## Цветовая маркировка брендов в портфеле

| Метка | Значение |
|---|---|
| 🟠 | Фокус — активно продвигаем (маркетинг, обучение, мотивация менеджеров) |
| 🔵 | В наличии — обеспечиваем ассортимент, но не продвигаем активно |
| без цвета / ⚪ | Фоновый/пассивный ассортимент |

Полная сводная таблица брендов — см. [«Портфель брендов»](../brands/index.md).

- **ПДЗ** — просроченная дебиторская задолженность.
